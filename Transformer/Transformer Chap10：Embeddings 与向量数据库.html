✦ Embedding 向量 4 大核心特征

1. 维度固定

同模型输出维度恒定（如 bge-small 512 维，OpenAI 1536 维）。

2. 稠密语义编码

非稀疏 One-Hot，连续浮点数空间承载近义词、同义词语义。

3. 词序敏感解析

基于 Transformer Encoder，能精准识别“人咬狗”与“狗咬人”。

4. 不含新事实

仅表示语义特征，不具备知识搜索推理能力（需配合检索）。

✦ 3 大核心应用场景

1
语义检索 (Semantic Search): 解决“退款条件”检索不到“怎么申请退货”的传统关键词错配难题。
2
聚类与去重 (Clustering/Deduplication): 自动识别千万条 FAQ 中的重复问题，实现工案自动分类与合并。
3
RAG 知识库召回 (Retrieval-Augmented Gen): 为 LLM 注入外部知识前，快速找出与用户 Query 最贴切的 Top-K 文本块。

当向量归一化后，三大度量在排序结果上完全等价！这也是向量库普遍首选内积加速的原因。

三种相似度度量选型判定表

余弦相似度 (Cosine)
只关注语义方向，无视文本长度。适合未归一化的原始文本 embedding 匹配。
内积 / 点积 (Dot Product)
计算速度极快 (无需除模长)。只要模型做了 L2 归一化，即为工业界检索首选。
欧氏距离 (Euclidean / L2)
衡量绝对空间距离。适合图像特征、物理空间聚类等对幅度敏感的场景。

✕ 延迟线性增长

✕ 无元数据过滤

Part B: 四大 ANN 向量索引原理可视化剧场 核心算法

HNSW (Hierarchical Navigable Small World)

借鉴“六度分隔”小世界理论与跳表 (SkipList) 思想。顶部稀疏层快速跨越超大空间距离，逐层向下精细化跳转，最终在底层找到最邻近节点。

时间复杂度:O(log N)
召回率 (Recall):95% ~ 99%
内存开销:较高 (额外存储图边)
Chroma / FAISS 默认:默认首选
⚡ 向量索引不可能三角：

准确率 (Recall) · 查询速度 (QPS) · 内存开销 (RAM)

Part A: 确定性 ID vs 随机 UUID 幂等性对比实验 避坑实操

连续点击“模拟重新入库 (Re-ingest)”按钮，观察两边的文档条数变化。

❌ 错误示范：随机 UUID + add() 当前总数: 5 条 
collection.add(
  ids=[str(uuid.uuid4()) for _ in docs],
  documents=docs
)

每次重新入库都会生成新 UUID，导致向量库严重垃圾膨胀、出现重复冗余召回！

✅ 最佳实践：确定性 ID + upsert() 当前总数: 5 条 
collection.upsert(
  ids=[f"{doc.source}::{i}" for i, doc in enumerate(docs)],
  documents=docs
)

通过“文件名 + 切块索引”生成确定性 ID，重复执行自动覆盖更新，保持完全幂等！

📌 add() vs upsert() vs update() 区别
  • add(): ID 存在时抛出 ValueError 终止。
  • update(): ID 不存在时忽略或报错。
  • upsert(): 存在则更新，不存在则插入（推荐）。
📌 Client() vs PersistentClient()
  • chromadb.Client(): 纯内存运行，进程退出数据清空。
  • chromadb.PersistentClient(path="./chroma_db"): 本地 SQLite + Parquet 自动持久化落盘。

10.6 Python 实战代码库、5 题互动测验与 11 条核心总结

Part A: 模块化 Python 实战源码

# 1. similarity_metrics.py
import numpy as np

def cosine_similarity(a: np.ndarray, b: np.ndarray) -> float:
    """计算两个向量的余弦相似度 [-1, 1]"""
    norm_a = np.linalg.norm(a)
    norm_b = np.linalg.norm(b)
    if norm_a == 0 or norm_b == 0:
        return 0.0
    return float(np.dot(a, b) / (norm_a * norm_b))

def dot_product(a: np.ndarray, b: np.ndarray) -> float:
    """计算点积/内积"""
    return float(np.dot(a, b))

def euclidean_distance(a: np.ndarray, b: np.ndarray) -> float:
    """计算欧氏距离 [0, +inf]"""
    return float(np.linalg.norm(a - b))

def l2_normalize(vec: np.ndarray) -> np.ndarray:
    """L2 归一化：使向量模长为 1"""
    norm = np.linalg.norm(vec)
    if norm == 0:
        return vec
    return vec / norm

# 验证恒等式: L2 归一化后 dot == cosine
v1 = np.array([1.0, 2.0, 3.0])
v2 = np.array([4.0, 1.0, 0.5])
n1, n2 = l2_normalize(v1), l2_normalize(v2)

print(f"Cosine: {cosine_similarity(v1, v2):.4f}")
print(f"Normalized Dot: {dot_product(n1, n2):.4f}")  # 完全相同！

Part C: 第 10 章 11 条核心知识点金句总结

1. 向量即语义

Embedding 将高维高熵的自然语言文本映射为稠密浮点数向量，捕捉深层语义。

2. L2 归一化神奇简化

向量归一化后，内积、余弦相似度与欧氏距离互相推导，内积计算最省硬件。

3. 警惕静默截断

Embedding 模型超出 max_seq_length 时通常静默切断，务必在入库前切分适当 Chunk。

4. 模型元数据锁

同一个向量数据库索引内绝对不能混用不同模型，换模型必须全量重建索引。

5. HNSW 分层图巅峰

以 O(log N) 时间提供 95%~99% 召回率，是目前综合性能最强的高维 ANN 索引。

6. 幂等性依赖确定性 ID

采用 filename::chunk_idx 确定性 ID 配合 upsert() 才能保障重新入库不膨胀。

7. Chroma Cosine 转换

Chroma 返回的是余弦距离 dist (1 - cos)，转化为相似度需做 1 - dist。

8. 标题路径前缀切块

给段落带上 # 一级标题 / ## 二级标题 上下文，彻底解决切块语义碎片化。

9. 向量检索的四大盲区

订单号/错误码、否定句、专有名词缩写、长数字精确匹配是向量检索的天然短板。

10. 混合检索 (Hybrid) 是终点

BM25 关键词匹配与 Vector 语义匹配结合（RRF 融合），覆盖 99% 以上真实搜索痛点。

11. 为第 11 章 RAG 筑基
