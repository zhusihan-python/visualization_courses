2.1 条件概率、链式法则与 Logits → 概率分布

语言模型的本质是一个条件概率分布预测器：根据历史 Token 预测下一个 Token 的概率。

概率链式法则 (Chain Rule of Probability)

P(我, 爱, 机器, 学习) = P(我) · P(爱 | 我) · P(机器 | 我爱) · P(学习 | 我爱机器)
连乘下溢陷阱 (Floating Underflow)

当句子较长时，连乘上百个小于 1 的概率（如 0.01100 = 10−200）会导致计算机双精度浮点数下溢为 0。

对数概率拯救 (Log-Probability)

利用对数性质将乘法转换为加法： ln P = ∑ ln Pi。数值始终维持在安全的负数区间（如 −4.6 + −3.2 + ... = −460.5）。

Logits → Softmax 动态实验室

调整未归一化的得分 (Logits)，观察 Softmax 如何将其映射为和为 100% 的概率分布。

2.2 Softmax 深度拆解与数值稳定性（溢出实验室）

为什么直接在 PyTorch/NumPy 中计算 Softmax 会导致 NaN？平移不变性的妙用。

朴素 Softmax (Naive)
pi = ezi ∑j ezj

当 zi > 709（Float64）或 zi > 88.7（Float32）时，ezi 溢出为 ∞。

数值稳定 Softmax (Stable)
pi = ezi − max(z) ∑j ezj − max(z)

平移不变性：所有 Logits 减去最大值，使得最大指数项不超过 e0 = 1。

溢出警报机制： 计算机使用有限位数存储浮点数。一旦指数项产生 ∞，计算结果将变成 ∞∞ = NaN (Not a Number)，导致整条神经网络反向传播梯度瞬间崩溃！

为基准 Logits [0, 1, 2] 叠加整体偏移量 C。体验朴素实现如何崩溃，而稳定实现如何坚如磐石。

2.5 交叉熵损失与困惑度 (Cross-Entropy & Perplexity)

评估模型预测质量的核心指标：从 Negative Log-Likelihood 到 Perplexity。

交叉熵损失 Cross-Entropy Loss
CE = − ln( ptarget )

惩罚离群预测：目标词概率 ptarget 越接近 1，Loss 越接近 0。

困惑度 Perplexity (PPL)
PPL = eCE = 1ptarget

直观解读：困惑度相当于模型在预测时，平均在多少个“完全等概率”的候选词中犹豫不决。

交互式 Loss 曲线: Loss = −ln(p)

拖动滑块或直接在图表上点击，查看不同目标概率下的 Loss 与 困惑度 PPL。

模型直觉评估
相当于在 4.0 个完全平等的词中随机发愣/犹豫。

💡 为什么刚初始化的 Transformer 模型 Loss 总是 10.8 左右？

在未经任何训练时，模型权重为随机初始化，输出概率分布趋近于均匀分布（Uniform Distribution）。 若词表大小为 |V| = 50,257（如 GPT-2 / GPT-3）：

ptarget ≈ 150,257  ⇒  Loss = −ln( 150,257 ) = ln(50,257) ≈ 10.825

🛠️ 代码 Debug 秘籍： 如果你在训练 GPT 类模型时，第 1 个 Step 的初始 Loss 远大于 10.8，说明你的词表索引或 CrossEntropyLoss 计算逻辑存在严重 Bug！
