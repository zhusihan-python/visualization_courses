📐 数学证明：为什么 Var(q · k) = dk ？

设两个独立的向量 q, k ∈ ℜdk，其分量满足独立同分布 qi, ki ∼ (0, 1)。 点积为 q · k = Σi=1dk qi ki。

由于独立性：E[qi ki] = E[qi] E[ki] = 0。 方差为 Var(qi ki) = E[qi2 ki2] - (E[qi ki])2 = Var(qi) Var(ki) = 1 × 1 = 1。

根据独立变量和的方差性质：Var(q · k) = Σi=1dk Var(qi ki) = dk。 因此标准差为 σ = √dk。除以 √dk 可以将方差强行缩放回 1.0，防止进入 Softmax 的平坦极值区导致梯度消失。

🎓 第 4 章 核心总结 Checklist

✓ 并行效率: Attention 将序列传输距离压缩为 O(1)，打破了 RNN 无法并行训练的致命缺点。
✓ 三投影矩阵: WQ, WK, WV 解耦了 Token 的“被检索属性”与“主动检索需求”。
✓ 缩放因子 √dk: 将点积方差从 dk 缩放回 1.0，防止 Softmax 极值饱和引发梯度消失。
✓ 因果掩码 Causal Mask: 在上三角置入 -∞，保证生成式 LLM 无法“偷看未来的答案”。
✓ 多头守恒律: 拆分多头提升多子空间表达力的同时，总矩阵参数量与计算复杂度严格保持不变。
✓ RoPE 旋转位置: 二维复数旋转矩阵实现绝对编码形式下相对位置依赖的完美数学内积性。
