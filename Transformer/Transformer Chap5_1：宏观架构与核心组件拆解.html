🏆 为什么 Decoder-only 大获全胜？

大语言模型 (LLM) 统一统治 NLP 的 4 大决定性优势：

1. 结构最简单： 无需 Cross-Attention 层，硬件算力利用率极大化。
2. 训练目标高度统一： 无损失地将任意文本转化为 Next Token 预测。
3. 天然支持 KV Cache： 流式推理生成时无需重复计算历史上下文 key/value。
4. 规模涌现效应： Scaling Law 在 Causal LM 上的外推表现最稳定预测。
MODULE 5.3.1 & 5.3.2

Embedding 查表与位置编码广播 (Broadcasting)

1. Token ID 查表 (Lookup Table) nn.Embedding(vocab_size, d_model)

Embedding 并不是真正的矩阵乘法，本质是利用 Token ID 作为索引进行 O(1) 高效查表取行。

Token Embedding Weight Matrix shape: (Vocab=5, d_model=4)
选中行 Embedding 向量 (d_model=4): [0.42, -0.85, 0.19, 0.61]

2. 位置编码广播相加 & Weight Tying 计算器 X = TokEmb + PosEmb

Xfinal ∈ &mathbb;RB × L × dmodel = TokEmb(B, L, dmodel) + PosEmb(1, L, dmodel)

PyTorch 在执行 TokEmb + PosEmb 时，沿着 Batch 维度（B）自动广播复制，实现全向量按元素无缝并行叠加。

Weight Tying 权重共享省能计算器 已节省 153.6 M 参数
词表大小 (vocab_size): 32,000 隐藏维度 (d_model): 4,096
💡 Weight Tying 机制：共享 tok_emb.weight 与最后的 lm_head.weight。在嵌入层与输出层之间共享参数，在不牺牲效果的前提下大幅节约显存！
MODULE 5.3.3

残差连接梯度高速公路 & LayerNorm vs BatchNorm

Part A: 残差连接 (Residual Connection) 梯度高速公路

∂(x + F(x)) / ∂x = 1 + ∂F(x)/∂x ≥ 1
网络层数 (Layers L): 32
子层导数 (∂F/∂x): 0.8
🔴 无残差 (Without Residual): 梯度在反向传播时连续乘算 (∂F/∂x)L。若导数小于 1，深度达到 30+ 层时梯度便快速衰减归零（Gradient Vanishing），深层无法更新！
🟢 有残差 (With Residual Highway): 反向传播恒有一个无衰减的项 +1！梯度直通最底层，保证了百层甚至千层 Transformer 的稳定训练。

Part B: 为什么 Transformer 必须用 LayerNorm 而弃用 BatchNorm？ LayerNorm vs BatchNorm

y = x - μ √( σ2 + ε ) · γ + β
LayerNorm 统计维度 (跨 Feature 维度 d_model) 独立处理每个 Token

无论句子长度 L 是 3 还是 500，LayerNorm 均沿着 d_model 维度单独求 μ 和 σ，完全不受 Padding 补零的影响！

Token 1 原始特征 (d_model=4): [2.0, 4.0, 6.0, 8.0]
均值 μ5.00
标准差 σ2.23
LN 输出(γ=1,β=0)[-1.34, ...]
BatchNorm 致命缺点 (跨 Batch & 序列长度 L) 文本变长/Padding 时崩溃
❌ 问题 1：变长序列 Padding 干扰

BatchNorm 跨 Sequence 长度计算 μ 和 σ。补零的 `` Token 会极大地拉低总体均值和方差，破坏真实 Token 特征。

❌ 问题 2：推理 (Inference) 依赖训练集统计

文本生成是一步步流式进行的，单 Token 推理时 Batch size=1，无法提供准确的 Batch 统计量。

MODULE 5.3.4 & 5.3.5

FFN 膨胀加工厂 & LM Head 词表投影

Part A: FFN 4× 膨胀加工厂 d_model → 4d → d_model

Attention 负责 Token 间的“信息交换”，而 FFN 负责对每个 Token 的通道特征进行“升维加工与知识存储”。

隐藏层维度 (d_model): 4,096 FFN 占 Block 参数 66.7%
Attention 参数量 (4·d2) 67.11 M
FFN 参数量 (8·d2) 134.22 M
Attention (33.3%) FFN 膨胀层 (66.7%)

Part B: LM Head 词表投影 & 采样 Temperature (B, L, d_model) → (B, L, V)

LM Head 通过线性层将最后的隐藏状态投影至词表大小，再以 Temperature 调节 Softmax 概率平滑度。

采样温度 (Temperature T): 0.70 适中创造力
