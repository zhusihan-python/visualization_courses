Module 6.2：三大致命避坑实验室

标签泄露实验：如果输入与标签完全对齐？

当 input_ids == labels 时，模型无需自回归预测，直接学习恒等映射 f(x)=x

注意力偷看实验：因果掩码 (Causal Mask) 的重要性

下三角阵 (Lower Triangular Matrix) 开关切换：观察 Token 0 是否偷看未来答案

4×4 Attention Mask Matrix
状态：安全遮罩中
下三角矩阵已启用。Token 0 (我) 的 Query 只能看见左侧已生成内容，右上角未来 Token 权重全被设为 -∞ (Softmax 后变成 0)。推理与训练机制严格对齐！

Padding 干扰实验：ignore_index = -100

变长批次补全 <pad> 占位符时，必须剔除其 Loss 贡献

批次内两条变长样本 (Batch Size=2):
Sample A: ["我", "爱", "机器", "学习", "。"] (Len=5, 无 Pad)
Sample B: ["今", "天", "<pad>", "<pad>", "<pad>"] label=-100
实际计算平均 CrossEntropy Loss: 2.84
真实 Token 损失贡献 (有效信号): 100%

正确做法：设置 ignore_index=-100，PyTorch 会在算 Loss 时直接跳过最后 3 个 <pad>，分母只除以实际 4 个有效词，梯度的每一个方向都是纯粹的语言信号。

Module 6.3A：为什么是 AdamW？—— 优化器赛道与解耦权重衰减

狭长峡谷 (病态曲率) 损失面优化器赛道

模拟 Transformer 不同层梯度尺度巨大差异的狭长等高线地形

● SGD (剧烈震荡)
● SGD+Momentum
● Adam (自适应)
● AdamW (解耦L2)

Adam vs AdamW 核心解耦数学

1. 传统 Adam (耦合 Weight Decay):
gt ← gt + λ · θt-1 (混入梯度) θt ← θt-1 - η ·
m̂t √v̂t + ε

缺陷：正则化项 λθ 被除以二阶矩 √v̂t。梯度大的参数惩罚反而变小！

2. AdamW (解耦 Weight Decay):
θt ← θt-1 - η ·
m̂t √v̂t + ε
- η · λ · θt-1

解耦优势：先算梯度自适应步长，再直接按固定比例衰减权重。全模型所有层衰减强度完全一致！

💡 工程结论：训练 Transformer 时，绝对不要使用 torch.optim.Adam(..., weight_decay=0.1)，必须统一换为 torch.optim.AdamW！
