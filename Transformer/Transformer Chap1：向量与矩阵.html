MODULE 01

向量——把文字变成空间中的箭头

在 Transformer 里，每个 Token 都用向量表达。几何上，向量就是带方向和长度的箭头。

提示: 拖拽向量终点点 试试

实时向量参数 (Live Vector)

坐标 $[x, y]$
[3.0, 4.0]
模长 $\|\vec{v}\| = \sqrt{x^2+y^2}$
5.00

为什么词向量能代表语义？

大模型通过高维向量嵌入（Embedding）将单词映射到空间中。含义相近的词在空间中距离更近；甚至**“语义关系”**对应着特定的向量加减位移（平行四边形法则）。

点击顶部「国王 - 男人 + 女人」按钮，观赏向量在空间中的加减加移！
MODULE 02

点积与余弦相似度——注意力机制（Attention）的灵魂

Self-Attention 第一步就是用点积测量 Query ($\vec{q}$) 与 Key ($\vec{k}$) 的相关度。

■ Query ($\vec{q}$)   ■ Key ($\vec{k}$)

点积公式拆解 (Dot Product Decomposition)

$\vec{q} \cdot \vec{k} = q_x k_x + q_y k_y$
(3.0 × 4.0) + (1.0 × 0.0) = 12.0
夹角 $\theta$
30.0°
余弦相似度 $\cos\theta$
0.866
注意力关联强度 (Attention Weight) 0.86
💡 直觉要点： 点积数值本质上是 $\vec{q}$ 的长度 × $\vec{k}$ 在 $\vec{q}$ 方向上的投影长度。方向越一致，点积得分越高！
