            🛡️ 护栏 1：严禁直接 eval() 执行模型参数
            防 RCE 注入
          

          

            Prompt 注入可能诱导模型传入 __import__('os').system('rm -rf /')。数学计算器必须用 Python ast.parse 白名单节点解析，严禁裸跑 eval()。
          

        


        

          

            ✋ 护栏 2：写操作强制人工确认 (HITL)
            Human-in-the-Loop
          

          

            将工具划分为 只读工具（查天气、搜知识库，自动放行）与 副作用工具（退款、发邮件、改数据库，挂起执行并弹窗等待人工点击“批准”）。
          

        


        

          

            ✂️ 护栏 3：Observation 长度截断与超时
            防上下文撑爆
          

          

            网页抓取或数据库查询可能返回 50KB 巨型 JSON。必须设置单工具 timeout=10s 并将返回值截断在 2000 字符以内，附带“内容已截断”提示。
          

        


        

          

            🔁 护栏 4：重复调用检测与优雅降级
            防死循环
          

          

            记录历史调用指纹 (tool_name, args_hash)。若模型连续 2 次以完全相同的参数调用同一工具，主动注入提示词强制模型换思路或直接总结回答。

Part D: 第 12 章 12 条核心要点总结矩阵

        

          

            
1. 模型不执行代码

            
LLM 只返回结构化 tool_calls JSON，真正运行函数并把结果喂回去的是你的宿主机程序。

          

          

            
2. Workflow vs Agent

            
确定性流程用 Workflow（稳定便宜），开放性多步任务才用 Agent（动态路由）。

          

          

            
3. tool_call_id 必须配对

            
每条 role="tool" 消息必须携带与 assistant.tool_calls 严格一致的 tool_call_id。

          

          

            
4. arguments 是字符串

            
协议中 function.arguments 是 JSON 字符串而非字典，解析时必须 try json.loads()。

          

          

            
5. Schema 即 Prompt

            
清晰的参数 description 和 enum 枚举约束，比在 system prompt 里写十条规则更有效。

          

          

            
6. 工具异常要喂回模型

            
捕获工具报错并作为 role="tool" 返回，LLM 往往能根据错误信息自动修正参数重试。

          

          

            
7. ReAct 循环本质

            
while 循环驱动 Thought → Action → Observation，直到 finish_reason == "stop"。

          

          

            
8. RAG 就是 Agent 的一个工具

            
把第 11 章的检索封装成 search_kb 工具，Agent 就能按需检索，无需每轮强行拼资料。

          

          

            
9. 必须设 max_steps 与预算

            
没有步数上限和 Token 熔断的 Agent，一旦陷入死循环会在几分钟内烧干额度。

          

          

            
10. 严禁裸跑 eval()

            
数学计算用 AST 白名单解析，代码执行放进 Docker/沙盒，严防 Prompt 注入 RCE。

          

          

            
11. 写操作接入 HITL 审批

            
发邮件、退款、删数据等不可逆工具调用，必须挂起等待人类确认后再执行。
