04. 四种激活函数「空间弯折」全景对比

点击任意卡片即可在上方主舞台切换对应激活函数，直观观察不同弯折机制对空间几何结构的改变。

1. ReLU 可分 ✓

负半轴硬折叠归零，在 (1,0) 处形成锐利折角（折纸效应）。

2. GELU 可分 ✓

Transformer 默认激活，平滑凹陷微弯，破坏共线并保持连续导数。

3. Tanh 可分 ✓

双曲正切 S 型双向挤压，将共线直线拉弯成弓形弧线。

4. 无激活 Linear 不可分 ✗

纯线性组合，点 A、(B,C)、D 始终卡在同一条直线上无法切开。

几何核心结论 (Geometric Takeaway)

无论是硬折（ReLU）还是软弯（GELU / Tanh），非线性激活函数的本质使命都是打破低维空间的线性共线约束。只要把卡在中间的点（B 与 C）从 A-D 的连线弦上“拉”或者“折”出来，高维/隐藏层空间中就必然存在一条超平面（直线）将两类完美分割！
