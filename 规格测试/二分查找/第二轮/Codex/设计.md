# 读一格，能排除几格？

## 1. 课程简报

一节约六分钟的离线自学课，面向刚学过数组和零基下标的学习者。给定七个按升序排列、尚未翻开的数，学生先找 25，再用相同数组找 24。结束时应能预测下一候选范围，并用本轮中点的值和升序条件解释为什么整侧都可以排除。中点取闭区间两端下标的平均值并向下取整。

## 2. 阶段分镜

| 阶段 | 动作与目的 | 画面和操作 | 事件 |
| --- | --- | --- | --- |
| 建立起点，约半分钟 | 分清下标和值 | 七个下标常驻，七个值都是问号。点一次翻开中点 | E1–E2 |
| 用一个读数排除整侧，约两分钟 | 从 18 推断未读数值的上界 | 先选下一范围和依据。提交后，横跨四格的虚线显示 ≤ 18 < 25；三个未读值仍是问号 | E2–E3 |
| 换边并命中，约一分钟 | 用方向相反的比较更新右端 | 依次读到 31 和 25，看到候选从三格缩成一格，再命中 | E4–E7 |
| 换目标并判断终止，约两分半钟 | 沿用同一规则，找出首次分叉 | 重新遮值找 24。前两次方向相同；第三次读到 25，先预测，再揭晓空区间。可翻开全部数核对 | T1–T7 |

## 3. 事件记录

题设数据为 `[3,7,11,18,25,31,42]`。E 表示找 25，T 表示找 24。编号表示教学动作顺序。程序根据中点比较推算两条路径，同一份事件数据驱动图、记录与点格回查。表内区间包含两端。

| 事件 | 查找程序的动作 | 状态和证据 |
| --- | --- | --- |
| E1 / T1 | 设置目标和端点 | [0,6]，7 项，0 次比较 |
| E2 / T2 | 读下标 3 的 18 | 范围仍为 [0,6]。18 小于两个目标。主例在此暂停 |
| E3 / T3 | 左端从 0 移到 4 | 排除 0–3，余 [4,6]，7 → 3 项 |
| E4 / T4 | 读下标 5 的 31 | 范围仍为 [4,6]。31 大于两个目标 |
| E5 / T5 | 右端从 6 移到 4 | 排除 5–6，余 [4,4]，3 → 1 项 |
| E6 / T6 | 读下标 4 的 25 | 主例 25 = 25，迁移题 25 > 24。两条路径第一次产生不同的比较结果。迁移题在此暂停 |
| E7 / T7 | 命中或排除最后一格 | E7 返回下标 4。T7 将右端移到 3，4 > 3，1 → 0 项 |

## 4. 画面与操作

| 学生的问题 | 视觉编码 | 回看和反馈 |
| --- | --- | --- |
| 看过哪几格？ | 七格位置固定，问号表示未读，双框和“比较点”标出刚读的格子 | 每个事件保留当时已读的下标；回退一步，才恢复当时的可见信息 |
| 为什么这一段能删？ | 虚线括住同一次排除的区段，线上写不等式。实线标出剩余区段。格子另有斜纹与文字 | 点已排除格会回到首次排除事件。E3 的图同时显示左端 0 → 4、7 → 3 项及四格共用的上界 |
| 两次查找在哪里分叉？ | T6 并列交代同一格的旧目标与新比较，T7 再并列展示两个结果 | 展开事件记录只看到本次查找已经到达的步骤；完成主例才开放迁移入口 |

每次点击推进一次读数或一次边界更新，便于停下比较。课中不模拟 CPU 耗时。全数组核对只在迁移题提交后开放，翻开的核对值不计入算法的三次比较。

## 5. 学习验证与自检

| 预测点 | 提交前可见 | 预期答案与揭晓 | 典型错因与反馈 |
| --- | --- | --- | --- |
| E2，找 25 | 升序、下标、18 < 25、当前七格、截至 E2 的记录 | 选 [4,6]，依据为左侧各值都 ≤ 18。直接提交进入 E3 | 若多留中点，要求检查 18 本身；若理由错，追问下标 2 的值至多还是至少为 18 |
| T6，找 24 | 已读 18、31、25，当前一格，两侧既有排除依据，记录止于 T6 | 选空区间，并指出唯一候选太大、其他位置已排除。提交后出现 T7 和两次查找的结论 | 若重新纳入左侧，追问哪条新证据能推翻第一次排除；若按次数判断停止，引导对照主例第三次比较 |

- **因果。** 第一次只读 18，排除的四格中有三个仍是问号。由升序确定方向，由取中点保证未命中时至多剩下一半，向下取整。
- **可追溯。** 在迁移终点点 42，回到 T5；点 11，回到 T3。两条浏览器路径均已验证。
- **可读。** 桌面 1280 × 800 实测首题的数组、选项和提交均在同屏。手机 390 × 844 采用上下排布，整页无横向溢出，首题提交需向下滑动。文字、线型及斜纹可独立区分状态。
- **可回看。** 已核对 E3 → E2 → E3 的格子和证据条一致；完成后可从头再学，初态恢复为七个问号。
- **简化透明。** 页尾注明教学数据和步序含义。三次比较、候选数 7 → 3 → 1（→ 0）均可按表重算。
- **预测与反馈。** 两种视口均实测漏答、错误区间、正确区间配错误理由，以及两题正确提交。T6 时日志仅有六行，答对才出现 T7。按两组选项作答即可提交。

六分钟为设计预算，实际完成时长与迁移效果仍需学习者试学。
