# 17-S2「让 VLAN 跨越 Trunk」｜Gemini 与修订版对比评审

**建议保留修订版作为学生自学入口，吸收 Gemini 的三结果预测和双图分叉对照。** Gemini 能在桌面和手机完成两道预测及总结。桌面拓扑清楚地把 SW1 出口、SW2 入口和各自的读数连起来。影响采用的主要问题是示范帧回看跳到另一帧、详情把拦截动作显示成标签值，以及手机主图缩小到难以读数。

对照对象为评审时位于项目根目录的 Gemini 课程（index.html） 与 [Codex 修订版](修订版/index.html)。Gemini 的 HTML 指纹为 `072c32c866d6`。制作人在随附的设计.md 中把浏览器检查标为待实测。下文记录独立实测结果。整理入库时，两份 Gemini 原件已不在项目根目录，仓库保留本报告和对应实测截图。

## 已复现的问题与复测条件

| 优先项 | 学生操作与实际结果 | 改完怎样验证 |
| --- | --- | --- |
| 端口回看串帧 | 首次到 M-E3，点标为可回看的 SW1 出口，仍停在 M-E3。完成主例，再点日志中的 M-E3、点击同一出口，跳到 **M-E6 的 VLAN 20**。该对象显示的是 VLAN 10 示范帧，首次放行发生在 **M-E2**。正常在 M-E9 回看 VLAN 20 则能到正确的 M-E6 | 分别从 M-E3、M-E9、V-E5 点击出口，应到 M-E2、M-E6、V-E4；各自返回原事件 |
| 手机图与总结裁切 | 390 × 844 下页面宽度为 390，无整页横移。主图却将 760 单位宽的 SVG 整体缩小，允许列表标题约 **4.5 CSS px**、数值约 **5.3 CSS px**。修订版的同一数字为 **16 CSS px**。桌面总结的 SVG 可视高度为 250 个单位，帧胶囊延伸到 276，实测约 19 屏幕像素落在裁切区外 | 手机使用适配窄屏的端口布局，遮住正文后仍可读出“仅 10”和“10、20”。总结页能同时看见两帧完整的标签状态。[Gemini 手机截图](Gemini复评截图/Gemini-手机-V-E3.png) · [修订版手机截图](修订版/手机迁移预测.png) |
| 标签字段混入动作 | 在 V-E4 看“当前详情”，字段显示“帧标签：✕ 出口拦下”。在 V-E5，标签位置显示“✕ 停在 SW1”。学生容易把处理结果当成帧携带的信息 | V-E4、V-E5 的标签字段均显示“无标签”，把“拦截，未发出”单列在出口处理结果中 |
| 查依据会丢掉未提交的选择 | 在 M-E5 先勾结果，点图中 SW1 允许列表，再点“返回当前进度”。返回 M-E5 后，刚才的勾选已清空。提交错答后的勾选能保留 | M、V 都分别在提交前选一项、回看读数、返回；仍能从原选择继续 |
| 事件记录提前列出后续步骤 | 刚读取本端列表、还在 M-E1 时，记录已列到 M-E5；正确提交后刚到 M-E6，就已列到 M-E9。V-E3 **没有**提前给出 V-E4 的答案，旧 GLM 的迁移泄题和卡死问题在 Gemini 中未复现 | 把已发生的事件与可继续学习的范围分别记录。M-E1 日志停在 M-E1，主例答对后跟到 M-E7 时才新增 M-E7 |

另外，“遮住讲解文字”会隐藏主图上方的讲解，但 V-E4 右侧的“当前观察要点”仍直接写出拦截原因。若用它测试学生能否仅凭图解释，右侧正文和结论性记录也需要收起。[遮文模式实测](Gemini复评截图/Gemini-V-E4-灰度遮文.png)

## 实测范围

- ego-browser 本地打开两份 HTML。Gemini 分别在 1280 × 800、390 × 844 从初态沿最短正确路径走完 M、V、分叉对照，再重置。复现错答与回看的一轮中，运行时错误记录为 0，页面加载的 HTTP(S) 子资源为 0。
- 两道题分别实测漏答、结论错、结论对但理由错、改正后继续。另实测键盘取证、提交与图内回看。正确提交分别落在 M-E6 和 V-E4，重置回 M-E0，迁移与总结重新锁定。
- 修订版本轮再走正确路径至总结，并对照 V-E3/V-E4 截图、390 像素宽的实际读数字号。修订版完整纠错和重置路径见[上轮复测](评审.md)。陌生题 B 保留给学生试学，尚无首次答案数据。
