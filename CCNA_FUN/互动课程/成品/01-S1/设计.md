# 01-S1 封装与分层

[离线课程](index.html) · [直接进入 01B](index.html#01B)

面向刚开始学网络分层的学生。两个独立任务各按 6–10 分钟预算。学完后，学生能在同一帧中圈出设备当前读取的地址字段、指出所属层，并根据交接方向预测以太网外壳的变化。图中包 P、地址和固定机位是教学示例。各片宽度不表示字节数。

## 输入与分镜

| 任务 | 主例 | 迁移题只改变 | 揭晓时画什么 |
| --- | --- | --- | --- |
| 01A 定位地址字段 | 读取目的 MAC | 选中字段改为目的 IPv4 地址 | 只框住当前字段，用一条指向链串起地址、协议头和处理层。另一栏保留原值 |
| 01B 追踪外层封装 | 发送端从 IPv4 交给以太网 | 改为接收端从以太网交给 IPv4，帧校验已通过 | 保持包 P、IP 头和载荷的内部关系，改变两侧帧头和帧尾的存在状态。接收端揭晓前已有外壳，揭晓后卸下 |

每轮先读字段或方向，再选结果与依据，再揭晓。事件号由任务、轮次和时刻组成。例如 01B-V0 仅见起始问题，01B-V1 读到方向并呈现交接前的帧，01B-V2 才显示交接后的包。END 可对照两轮结论。事件记录只展开到当前画面。各任务独立保存当前进度、选项和回看位置；由同节导航切换任务可继续先前操作。浏览器刷新重新开始。

结论错时提示重读字段位置或交接方向；理由错时保留并锁定正确结果，追问决定条件，请学生重新选择依据。每个已读时刻可以从主图回查本轮读数，已揭晓时刻还可以定位结果。回看时用前后步或返回当前进度。按“重置本任务”重新隐藏证据，仅重置当前任务。

## 制作者自检

| 范围 | 检查方法与结果 |
| --- | --- |
| 独立核算 | 01A 的两轮分别得到链路层、网络层。边界用例只选目的 IP，两种地址虽同屏，只有 IP 字段被选中。01B 两轮分别加、去帧头帧尾。接收端边界用例上交包 P，内层身份保持。两个边界用例留给试学 |
| 程序路径 | 用 Node 执行页面脚本及事件处理器，以轻量 DOM 适配器走四轮，检查漏答、错误结论、正确结论但依据错、回查后改正、结果事件号和单项重置。四轮断言通过。该检查覆盖逻辑，不覆盖浏览器命中区域与布局 |
| 浏览器复核 | 制作端交接时待独立实测。建议分别从 01A 和 01B 直达入口进入，检查有证据时可答、答对后才画变化；在 1280 × 800、390 × 844 检查目的 MAC 换行、IP 包嵌套、键盘焦点、回查及返回位置 |
| 学习效果 | 待试学。用未见过的字段或接收端情境，记录首次判断、所指字段或外壳、耗时和是否需要提示 |
